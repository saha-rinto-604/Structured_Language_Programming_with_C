# C Programming Foundations

Independent C programs from structured-programming coursework and self-study. Exercises cover strings, arrays, structures, recursion or iteration, and elementary number algorithms.

## Topics

- Factorials, Fibonacci numbers, greatest common divisors, and digit operations.
- Palindromes, prime-number exercises, and integer reversal.
- String length, word counting, sorting, case conversion, and character frequency.
- Struct-based student and triangle examples.

## Compile an exercise

Use GCC or another standard C compiler. Each file is an independent program; compile one at a time rather than linking every file together.

```bash
gcc "Find Factorial.c" -o factorial
./factorial
```

Read each program for expected input. Very long exercise filenames may require Git long-path support on Windows. Coursework input assumptions and error handling vary; these examples are not a production library. Use synthetic values when trying student-record exercises.
